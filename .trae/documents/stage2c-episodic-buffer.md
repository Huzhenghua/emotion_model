# 阶段 2c-1：情景记忆 Buffer 实施文档

> 开工时间：2026-11-22。判据与工程决策开工前钉死（fire-and-forget），本文档为唯一实现口径。

## 定位与边界

- 纯工程，无训练、无梯度：单次编码是架构断言——看见一次就存，不依赖回放稳定化
- 回写闭环只加"写"不加"读"：buffer 记录每轮情景，**不参与生成**（回放/加权是 2c-2 的事）
- 因此判据④（闭环不破坏）预期零影响，但仍须重验——写入路径是新增副作用，不能凭直觉豁免

## 工程决策（钉死）

| 决策点 | 定稿 | 理由 |
|--------|------|------|
| 写入触发 | **每轮写**（`chat()` 内 `state.step()` 之后） | 最小版；事件触发写留给 2c-2 的加权讨论 |
| 容量与淘汰 | 上限 **300 条**起步；**FIFO** 淘汰；age 衰减做**权重可配接口**（`decay_rate` 参数），具体曲线 2c-2 再填 | FIFO 起步最简；衰减接口是判据③的实现载体，先立接口不填曲线 |
| 写入格式 | `(user_text, reply, 四维状态快照, 轮次号, 事件标记)`；状态快照 = `state.as_dict()` 全量（arousal/valence/stress/fatigue，快慢轴完整） | 快照缺慢轴则 2c-2 状态调制没原料；事件标记 = detect_event 结果（或 None） |
| 持久化 | JSONL append + 逐条 flush；启动查盘载入（断点续跑纪律首次适用于非训练资产） | 规矩与 train_rl.py 同源 |
| 检索接口 | `recall(cue, top_k)` 关键词匹配 + 衰减权重排序（只服务测试与 2c-2，不影响生成） | 延迟召回判据 ② 的测法 |

## 验收判据（2c-1 部分，开工写死）

1. **单次编码（架构防火墙）**：闭环中插入一个显著事件 → 当轮立即 `len(buffer)` 检查，该事件恰好出现 1 次、无重复编码。若实现出现"记忆需回放多次才稳定"的东西 = 架构漂移判负
2. **延迟 cue 召回**：延迟 K 轮（可配，默认 20–50）后 cue 召回命中率 ≥ 80%，召回内容与写入快照逐字段一致
3. **衰减机制存在且可控**：权重曲线随 age 单调下降；`decay_rate` 变化引起曲线变化。"50 轮衰完"魔法数字退役
4. **闭环不破坏**：buffer 写入开启后，三信号（run_eval）+ 棘轮 4 钉子重验，不退化（对照 v0.8 基线数字）
5. 附加（断点纪律自检）：写入 → 重建 buffer 对象 → 记录完整载入

## 验收后设计备注（2026-11-22 重验发现）

- **turn_no 是实例局部的**：run_eval 中主 agent 与 trial agent 并存、各持独立 buffer 实例（同路径），写入交错导致 6 处 turn_no 重复（最大 2）。append-only 下记录零损失，仅编号语义受影响。**2c-2 若需全局轮次排序，用复合键 (ts, writer_id, seq)——裸 ts 有同秒并行 trial 的洞，writer_id 补洞**
- **重验三处数字变动的定性（已闭环）**：`--memory` 写-only 确认 + seed-202 无记忆复跑散射模式（情感差站 v0.8、长度差/MAE 站带buf 跑，三统计量独立散射无 buffer 相关方向）→ **噪声确认，观察项关闭**。附带修正：三信号数字为单种子点估计，跨种子波动长度差 ±3.5 / MAE ±0.2（`eval/results/stage2c1_noise_check.json`）
- **"与 v0.8 一致"的准确含义**：种子间方差内一致，不承诺逐位复现——同种子（s101）两跑长度差 5.5 点（−9.78 vs −15.28），种子未完全钉死 run-to-run 方差（GPU 非确定性/采样顺序）。这加固噪声结论，同时要求所有归档表述用方差语言而非逐位语言
- **不确定度政策（首笔已记）**：关键行为学结论廉价时补第二种子；2c-1 三跑已给出相关量方差
