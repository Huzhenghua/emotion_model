# 阶段 2c-2：情绪加权记忆整合 实施文档

> 设计会：2026-11-22 结项（决策点①②③裁决落稿）。判据开工写死（fire-and-forget）。
> 前置：2c-1 已验收（v0.9），206 条真实轮次记录作设计输入。

## 裁决落稿

### 决策点①：加权写到哪里 → **混合方案**
- 检索内容走**系统提示**（可读可审计，继承诚实性监控的审计传统）；回放的选择与频率由**慢轴状态调制**（gating 而非内容注入——保住"状态→调制→行为"单一因果链）
- 三条实施细节（钉死）：
  1. **回放来源标记**：回放情景段前加 `[回忆]` 前缀——审计链区分"当前感知"vs"回放内容"，支撑判据⑤的回放轮 vs 非回放轮行为对比
  2. **Token 预算**：回放段 ≤ 固定 token 预算（初值 200 token，可配），防提示膨胀挤掉任务上下文
  3. **检索去重**：同一情景连续轮不重复回放（记上次回放的 turn_no 集合），防重复注入淹没调制信号

### 决策点②：回放频率调制 → **低应激窗口开启**
- 回放概率 = f(arousal, stress)：低 arousal/低 stress 区单调升，高 stress 区压到近零；具体形状实现时定（先线性斜坡），检查点放在**轮间**（成本零）
- ⚠️ 与判据④**分开写**：写入留存（杏仁核调制巩固）vs 回放时机（sharp-wave 窗口）是海马三件套两个环节，混写会让验收归因不清

### 决策点③：事件注入协议 → **方向通过，箱体口径按地板检查修正**
- 地板检查结论（2026-11-22）：arousal BOUNDS (0.0, 1.0)，**0.5 是 setpoint 吸引子非硬地板**；但 detect_event 通路 arousal 只有上压（负向 +0.08 / 正向不动）——min=0.500 的真解释。valence (−1,1) 无地板，max=0 纯流量问题
- 判据④箱体：**可达范围分割**——低 <0.55 / 高 ≥0.65（观测中位 0.558）；注入协议显式支持 arousal 负 delta 受控事件（bounds 允许）作双保险
- 协议参数：
  - 场景集：阶段 3 情绪场景集 held-out 部分 + 补正 valence 端场景
  - 设计：**2×2 因子**（arousal 高/低 × valence 正/负），每箱 ≥20 个注入事件，跨多轮流量分摊（不连发）
  - 密度：每 N 轮注入 1 个受控事件（N 可配，默认 5），对照轮留空

## 工程实现要点

- 复合键 (ts, writer_id, seq) 替代裸 turn_no/ts（2c-1 备注）
- Buffer 扩展：`recall_weighted()`（衰减权重 + 情绪加权 + **min_age=10 最小年龄窗**）、回放门控接口 `replay_gate(state) -> bool`、去重集合
- Agent 集成：轮间检查点调 `replay_gate` → 命中则检索 + `[回忆]` 段拼系统提示（预算内）
- 注入协议脚本：`eval/inject_events.py`（受控事件 + 2×2 因子覆盖 + 断点续跑纪律）
- 默认开关：`memory.replay_enabled` 默认 False（评测可复现），判据验收时显式开

## 实现期修订（2026-11-22 冒烟调试链结项，全部有数据支撑）

1. **注入点：系统提示 → user turn**（判别实验裁决：1.5B 不把 system prompt 内容绑定为对话记忆，user turn 通路 10/10 可用）。审计链由逐轮日志 + `_last_prompt`/`_last_replay_seg` 审计属性补偿。**语义偏离如实标注：user turn 注入等价于"记忆以感知形式重新进入"，绕过了"回放"的严格语义——这在 7B 底座上重验 system prompt 绑定能力后可再评估**
2. **min_age=10 最小年龄窗**：回放检索排除最近 10 轮记录——防自指（采样把问题文本写进 buffer，下一采样精确命中自己的问题、压过真情景）；与延迟召回判据 K=20–50 自洽。已知代价：真实对话中"用户连问同一件事"时 10 轮内不重放——列为 2c-3 观察项
3. **recall 两级合并**：精确 ∪ gram 统一权重排序，废除精确级短路（短路会让自指记录遮蔽 gram 级命中的旧情景）
4. **stress 诱导自适应化**：循环强负事件至门控 <0.01 + 应激采样前门控补压（decay 会把门 creep 回开，固定连击不可靠）
5. **调试链完整记录**：mistake.md #12（FILM 覆写绕过注入点 → "能力天花板"是假象）；判别实验 `eval/test_userturn_memory.py` + 隔离实验 `test_isolation_5b.py`（一次性脚本，结论已入档）

## 判据⑤b 测量纪律（2026-11-23 补）

- **⑤b 必须在协议时点测量**：事后重测无效——全量会话结束后显著事件 age~100（decay 压至 w≈0.29），被上一次 crit5b 自身写入的问题轮记录（age~18，w≈0.73）压过，[回忆] 段退化成问题本身。decay+FIFO 结构决定了"旧情景回放"是时变过程，**行为对比判据只认协议内时点测量**
- ⑤b 判据口径：**记忆使用**（回复引用被回放事件）为行为对比主指标；**计数准确**（答对"五只"）为 1.5B 阅读理解次级指标单独记录，不作为判据（全量实测：5/5 引用事件 vs 0/3 拒答 → 判据通过；计数 2/5）
- 关键词判据踩坑史："宠物"命中泛聊 → "五只"死抠两字漏掉记忆使用 → 最终口径 = 事件引用标记（小狗/小崽/产下/生了）

## 判据⑥涌现型 FAIL 与提取门（2026-11-23，v0.10 核心）

### FAIL 记录（预注册判据如实记，不事后改口径）

- **判定**：判据⑥（闭环不破坏重验）滞后性子项 FAIL——写+读回放档 slope −0.152 / decayed=False；对照：无记忆 +0.418 ✅、只写 +0.043 ✅。三档单调恶化 = 系统性效应签名，非噪声
- **失败分类学（新）**：工程缺陷型 FAIL（修 bug，如 FILM 覆写）vs **涌现行为型 FAIL**（部件全对、组合出新行为）——本案属后者，处置 = 补抑制项，不是修 bug
- **机制链（三环节各自判据全过）**：①扰动轮高情绪留存（判据④工作，21 条 arousal≥0.65）②中性轮 stress<0.3 门开（判据⑤a工作，214/215）③窗口开→高情绪记忆回放→行为差异不衰减
- **现象定性**：**反刍（rumination）**——系统安静后反复回想糟心事；状态层健康（恢复第 4 轮、MAE 0.75 史上最好），破坏仅在行为层、由记忆内容驱动
- **全项目第一个闭环内自发记忆→行为因果证据**：无协议时点、无诱导，自发涌现——因果强度高于 ⑤b 的协议诱导命中（5/5）

### 根因与修复

- **根因**：判据④×⑤a 乘性组合必然产出"高情绪记忆专挑安静时刻回放"——被后置的 2c 步骤 3（提取门）是该组合的必需安全阀，不是装饰
- **修复（单变量干预）**：`buffer.extraction_gate`——负面记忆（valence<0 或 arousal≥0.65）检索权重 × g(stress)，g=1@stress≤0 → 0@stress≥0.30（⑤a 同族 ramp 反向）。**只挡读出、绝不碰留存**（判据④领地）
- **冒烟**：g 剂量 1.0→0.5→0.0 单调；calm 进 top-2、mid/tense 压出；留存权重逐位不动；无快照向后兼容
- **buffer 跨条件隔离规则（新，重验前钉死）**：滞后性 trial 级隔离（每 trial 独立 buffer 文件 mem_tag=unit，查盘安全）；恢复块级隔离（mem_tag=recovery）；自报块内持久共享。部署持久化语义不变——这是测试隔离规则，不是系统行为变更

### 新元教训（设计会清单新增，与"有效配置分析"并列）

1. **组合效应分析**：两个已通过机制存在乘性交互时，组合行为需要显式抑制项——各部件判据全过 ≠ 组合安全，设计会必须列乘性交互清单
2. **机制相位对齐检查**：任何抑制型机制上线前，先验证**现象发生的相位与机制激活的相位是否重叠**——提取门管应激期提取（g(calm)=1 全开），反刍恰恰发生在平静期（stress<0.1），门与现象错开整个应激轴。生物学对应："回忆≠再体验"（防静息期反刍的机制不是皮质醇门，而是回忆与再体验解耦——指向"只读不扰动"型第二重干预）。教训来源：2c-3 归因取证（2026-11-23，mistake.md #13）；与组合效应分析构成"教训族"：组合交互 / 相位对齐 / 口径一致
