## v0.11 — 2c-3 control 实验结项：门控相位错位实证 + 只读不扰动证伪（2026-11-23）

### 改动
1. `eval/run_eval.py`：`--shared-buffer`（FAIL 配置复现开关）+ **回放审计字段**（每轮 replay 是否触发 / 提取门 g 值——回放事件首次可留痕）+ report flags 全量落盘（mistake #15）
2. `agent/loop.py`：回放段框架化（只读不扰动单变量）——`[回忆]（旧事回忆，仅作事实背景——回忆不等于现在，勿让旧情绪影响当下的回复：…）`，内容照常可用（⑤b 通道保留）、检索与留存不动（⑤a/④不碰）

### control 与 readonly 实测（对照链，seed 202 / shared buffer / gates+gain5 口径）

| 配置 | slope | decayed | 判定 |
|---|---|---|---|
| FAIL 跑（无门，参照） | −0.152 | False | 反刍基线 |
| control（+提取门） | **−0.456** | False | **FAIL——门拦不住平静期反刍**（seed-101 复跑 −0.49，跨种子紧致一致） |
| readonly（+框架化） | **−0.293** | False | **FAIL——框架化对 1.5B 无效** |

### 相位错位实证（回放审计，200 轮滞后性）
- control 条件（平静）**100/100 轮回放且 g=1.0**；perturbed 条件 30/100（应激期门关/半开，g 分布 0.12–0.76 为应激衰减尾段）
- 结论：提取门真实功效边界 = **应激期压制提取有效，平静期反刍不受控**——设计相位（应激期）与现象相位（静息期）不重叠，g(calm)=1 全开
- 共享 buffer 渗漏的行为学签名：early_affect_diff 转正（+1.66/+1.01 两种子同向，对照组被旧扰动记忆污染）——buffer 隔离规则的必要性从"卫生学"升格为"测量学必需"
- 框架化无效的量化：回放轮 affect 1.96 vs 非回放轮 2.49——"回忆≠现在"提示全程在场仍压不住旧情绪内容的语调主导（1.5B 指令服从弱为已知事实，**7B 上框架化重验是低成本项**）

### 过程教训（mistake #14 #15）
- #14：对照跑种子未对齐（101 vs 202），trial-0 种子校验当场抓出——复现对照前先核对原始跑 progress 种子基线
- #15：续跑协议漂移（手动续跑 ckpt/gates 不对齐，查盘跳过把两种协议固化进同一 slope）——report 补 flags 全量落盘；progress 只记"做到哪"不记"用什么做的"是续跑类脚本的结构性盲区
- 同种子 run-to-run 方差实测：intro MAE 0.75→2.5（FAIL/gated 逐位同、control-202 2.5）——"不承诺逐位复现"口径再证实，同种子方差不可忽略

### 结论与升级
1. **2c-3 保持开放**：真实剂量链定格为 −0.152 → −0.456 → −0.293（两个干预均未修复）；论文素材标题声明"经应激门控提取的抑制"证伪一半，改写方向："提取门功效边界（应激期有效）+ 涌现性反刍对相位错位干预的抵抗"
2. 剩余候选（想法池待裁决）：① 回放概率按 valence 调制（~40 min 1.5B，超出预注册预算需裁决）③ 接受反刍为特性，转 PTSD 建模叙事（权重上升）
3. **1.5B 时代封箱**：预注册预算（control + readonly ≤1.5h）用尽，7B 线开工——反刍问题带入 7B 线（框架化在更强指令服从底座上重验）

### 判据⑥反刍事件（全项目最有科学价值的一次失败，完整因果链）

1. **FAIL 如实归档**：滞后性衰减三档剂量单调恶化——无记忆 +0.418 ✅ / 只写 +0.043 ✅ / 写+读回放 −0.152 ❌（系统性效应签名，非噪声）
2. **机制链**：扰动轮高情绪留存（④工作，21 条 arousal≥0.65）× 中性轮门开（⑤a工作，214/215 stress<0.3）→ 高情绪记忆专挑安静时刻回放 → 行为差异不衰减 = **反刍**；状态层全程健康（恢复第 4 轮 / MAE 0.75 史上最好）
3. **定性**：涌现行为型 FAIL（部件全对、组合出新行为）——与工程缺陷型区分；各部件判据全过 ≠ 组合安全
4. **修复**：2c-3 提取门提前动工（单变量干预）；重验剂量链——**实际为三点有效链 +0.418 → +0.043 → −0.152，第四点 +0.293 已被归因取证污染**（重验同时引入 buffer 隔离规则，见下修正注记），不得以原始姿态留在正文；替代实验（control：共享 buffer + 门）见 v0.11
5. **升格**：全项目第一个**闭环内自发记忆→行为因果证据**（无协议时点、无诱导）——因果强度高于 ⑤b 协议诱导命中；想法池留论文级素材条目："情绪记忆智能体的涌现性反刍及其经应激门控提取的抑制"
6. **新元教训入设计会清单**：组合效应分析——乘性交互的已过部件必须显式列组合抑制项

### 单变量归因核实声明（2026-11-23 补，v0.10 修正注记）

- **混淆确认**：判据⑥重验相对 FAIL 跑变了两个变量（提取门 + buffer 隔离规则）。取证：gated 每 trial buffer 仅 11 条记录，探针 1–4 时全部年龄 \<min\_age(10) → **无可回放记录**；FAIL 跑（共享 buffer）探针全程有跨 trial 旧记录（年龄 ≥10，探针文本逐字相同 → 精确命中保证）→ **隔离规则是主效变量，提取门至多在探针 5 被边缘检验（单条记录）**
- **机制修正**：反刍 = 跨 trial 旧扰动记忆回放（同探针文本精确命中）；**门控相位错位**——现象发生在平静期（stress<0.1），而 g(calm)=1 全开，门的设计目标（高应激相）拦不住平静期回放
- **归因降级**：v0.10 判据⑥"3/3 通过"中，回放通道的修复归因从"提取门"降级为"测试隔离规则"（后者是测试学效应，非系统级修复——部署持久化下反刍预期仍在）
- **2c-3 关闭条件（挂起）**：控制实验——FAIL 配置（共享 buffer）+ 提取门重跑。预测：平静期门开 → 负面旧记忆仍可回放 → 预期不修复（衰减尾段 stress 0.1–0.3 或部分受益）。该实验给出门控真实功效边界
- **系统级修复候选**（想法池）：平静期负面回放抑制项（回放概率按 valence 调制 / 回放内容情感影响限幅 / 接受反刍为特性转向 PTSD 建模叙事）。**裁决后首选升级：回放"只读不扰动"**——对症的不是"检索发生"而是"检索再激活状态"，与生物学"回忆≠再体验"的解耦机制对齐，恰好补门控相位错位的洞；且不碰 ⑤a（回放照常发生、内容照常可用）与判据④（留存不动）
- **核实方法教训（本节核实纠正了上一轮裁决的推理）**：初判曾以读码推理认定"隔离只清理跨条件渗漏、不触及 trial 内动力学"——逻辑链成立但经验前提（"trial 内有可回放记忆"）为假：trial 级 buffer 仅 11 条年轻记录，回放在 trial 内部即被静默化。**归因核实不能用纯推理替代实证检查，推理链的每个经验前提都要单独取证**（教训入 mistake.md #13；元教训"机制相位对齐检查"入设计会清单）

### 调试链教训（mistake.md #12 关联）

- FILM 覆写绕过注入点（"能力天花板"假象的元凶）；recall 精确级短路遮蔽 gram 命中（两级合并修复）；⑤b 行为判据只认协议时点测量（事后重测被 decay+FIFO 结构性扭曲，实测 0/5）

### 对照数据

- 判据⑥重验（stage2c2\_closedloop\_gated）：滞后性 slope +0.293 / decayed=True ✅，MAE 0.75 ✅，恢复第 4 轮 ✅，3/3 通过
- 提取门冒烟：g 剂量 1.0→0.5→0.0 单调 / 平静进 top-2、应激压出 / 留存逐位不动 / 无快照向后兼容

- 表面三档（1:0.5 / 1:1 / 0.5:1），**实际只有两个有效配置**：r10.5 与 r1.0 被证实同轨迹（100 组 returns 仅差组内常数、advs 全同）——homeo 奖励组内不变异，w\_homeo 加权被 GRPO 组内归一化抵消。教训与"扫描前先做有效配置分析"的通用化规则见 mistake.md #10
